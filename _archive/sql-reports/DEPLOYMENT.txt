TECHNICKÉ POZNÁMKY
================================================================================

PostgreSQL verze: 15+ požadavek
- Používáme PERCENTILE_CONT() (PostgreSQL 9.4+)
- generate_series() pro heatmap
- FILTER (WHERE ...) klauzule pro aggregate (PostgreSQL 9.4+)
- JSON agregace v audit logu

Schéma: Bez cross-schema FK (záměrné)
- Tabulky v různých schématech (identity, catalog, orders, tickets, resale, audit)
- JOINy jsou možné, ale bez foreign key constraints
- Validace na aplikační vrstvě

Performance:
- Všechny reporty jsou optimalizovány pro ~100ms-300ms runtime
- LEFT JOINy se používají pro vč. zón bez prodejů
- Aggregate Functions s FILTER pro přesné počty

GDPR Compliance:
- Report 03: Filtruje anonymized_at IS NULL
- Report 07: Bez jména/e-mailu, pouze user_id
- Soft delete: deleted_at sloupec ignorován
- Audit log: Immutable, žádné DELETE/UPDATE
